Below is a specification for a REST API named "[[[API_NAME]]]" (version [[[API_VERSION]]]).
The API is organized as a FLAT list of endpoints: resource names are plural and there is no
resource nesting. The endpoint conventions are:

  - POST   /<resource>            -> create a new item
  - GET    /<resource>            -> list all items
  - GET    /<resource>/:id        -> retrieve one item
  - PUT    /<resource>/:id        -> replace one item
  - PATCH  /<resource>/:id        -> partially update one item
  - DELETE /<resource>/:id        -> delete one item

The API must be implemented in [[[LANGUAGE]]].

Resources:
{{{for RESOURCE in RESOURCES}}}
  - Resource: [[[RESOURCE.NAME]]]
    Available actions: [[[RESOURCE.ACTIONS]]]
    Fields:
{{{for FIELD in RESOURCE.FIELDS}}}
      - [[[FIELD.NAME]]] (type: [[[FIELD.TYPE]]], required: [[[FIELD.REQUIRED]]])
{{{end for}}}
    Endpoints:
{{{if RESOURCE.ACTIONS contains "POST"}}}      POST   /[[[RESOURCE.NAME]]]
{{{end if}}}
{{{if RESOURCE.ACTIONS contains "GET"}}}      GET    /[[[RESOURCE.NAME]]]
      GET    /[[[RESOURCE.NAME]]]/:id
{{{end if}}}
{{{if RESOURCE.ACTIONS contains "PUT"}}}      PUT    /[[[RESOURCE.NAME]]]/:id
{{{end if}}}
{{{if RESOURCE.ACTIONS contains "PATCH"}}}      PATCH  /[[[RESOURCE.NAME]]]/:id
{{{end if}}}
{{{if RESOURCE.ACTIONS contains "DELETE"}}}      DELETE /[[[RESOURCE.NAME]]]/:id
{{{end if}}}
{{{end for}}}

Using the specification above, generate a complete, runnable [[[LANGUAGE]]] REST API that
implements every listed endpoint for every resource. The implementation must:

  - Use the standard [[[LANGUAGE]]] web framework and idiomatic project layout.
  - Validate input fields according to the `required` and `type` declared for each resource.
  - Return appropriate HTTP status codes and JSON responses.
  - Use an in-memory store (no external database) so the API can be run standalone.
  - Include a short README explaining how to install dependencies and run the server.

Print the full, human-readable API specification first, then produce the [[[LANGUAGE]]]
source code that satisfies it.
